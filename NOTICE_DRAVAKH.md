# Dravakh Map Studio

Dravakh Map Studio is a project-specific derivative of **Azgaar's Fantasy Map Generator**.

Upstream project:
- https://github.com/Azgaar/Fantasy-Map-Generator

Original author:
- Azgaar / Max Haniyeu

License:
- MIT

The upstream `LICENSE` file is preserved in this repository. Dravakh-specific branding, data, presets and workflow documentation are additions for the internal cartography pipeline of **Dravakh: House of Habits**.

`Nova Valyria OS` remains an internal development codename only. It must not appear in player-facing game content.
