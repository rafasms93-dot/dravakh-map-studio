# Upstream policy

Dravakh Map Studio is derived from Azgaar's Fantasy Map Generator under the MIT license.

Policy:

- preserve upstream attribution and `LICENSE`;
- keep project-specific changes isolated and reviewable;
- prefer small, auditable customizations over invasive rewrites;
- periodically compare against upstream before adopting major engine updates;
- never silently replace canonical Dravakh worldbuilding with new upstream-generated defaults.
