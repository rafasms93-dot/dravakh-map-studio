# Canonical rules

1. The internal project codename may remain `Nova Valyria OS` in development-only contexts.
2. The player-facing game name is `Dravakh: House of Habits`.
3. `Nova Valyria` must not appear in player-facing game content.
4. The kingdom name is chosen by the user; `Dravakh` is the default suggestion.
5. Exactly 15 canonical provinces define the current kingdom structure.
6. Highhallow is insular.
7. Geography precedes political borders: relief → rivers → coastline → forests → routes → borders.
8. Azgaar / Dravakh Map Studio is an authoring tool, not the final in-game visual interface.
9. Final art is separate from technical cartographic geometry.
10. Browser-only autosave is never the sole canonical source of an approved map.
