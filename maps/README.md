# Dravakh map sources

This directory is reserved for durable Dravakh cartography artifacts.

Recommended contents:

- approved `.map` milestone files;
- exported SVG used for art/reference;
- GeoJSON/JSON integration exports;
- checksum or release notes when a milestone becomes canonical.

Do not commit temporary browser autosaves or unverified random generations as canonical map sources.
